# Provenance and licences

## Origin of the mirroring logic

`lib/mirror-core.mjs` descends from the GitCode mirror script of the Uni Mobile
app. The sequence "ensure the release, reuse an identical asset or refuse to
overwrite it, two-step `upload_url` upload, wait for the asynchronous
registration, anonymous read-back compared by size and SHA-256", the redirect
checking and the stall watchdog come from that script. Everything else was
written for this repository: the request protocol, the SSH host wrapper, hash
binding, release-race handling, retry-before-reupload, input validation and the
Action. The upload path was rewritten after measuring that `fetch` buffers a
streamed request body in memory.

## Code that was read but not copied

The UniClipboard Desktop repository (<https://github.com/UniClipboard/UniClipboard>) contains a similar script
(`scripts/mirror-desktop-installers-to-gitcode.mjs`, blob
`4a07117a96155afcec5f96f6702982c0c919df7b` at Desktop HEAD
`101ffb38e83631b0763556ae4432c3554bd58db8`). Desktop is licensed
**AGPL-3.0-only**. Nothing from the Desktop script, its Python host wrapper or
its tests was copied or translated here; it was used only to compare behaviour
(it lacks the stall watchdog and progress log of the Mobile script). If Desktop
code is ever wanted in this repository, the copyright holders must decide
whether to relicense it first.

The Python forced-command wrapper of Mobile was used as a behavioural reference
for the protocol idea only; `lib/host.mjs` is a new Node implementation with a
different request format and a host-side allow-list.

## Third-party packages

`dist/index.mjs` bundles `@actions/core` and `@actions/glob` and their
dependencies. Their licences are reproduced in `dist/THIRD_PARTY_LICENSES.md`,
regenerated by `npm run build`. Development tools (`esbuild`, `yaml`) are not
shipped.
